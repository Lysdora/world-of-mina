# World of Mina

Guide personnel pour créer un action-RPG en pixel art (façon Zelda et World of Warcraft) avec Godot Engine.

Chaque leçon est écrite à partir du code réel du projet Mina, pour retenir ce qui a été fait et pouvoir y revenir.

Site du guide : https://lysdora.github.io/world-of-mina/
